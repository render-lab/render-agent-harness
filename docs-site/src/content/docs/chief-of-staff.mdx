title: Chief of Staff Bundle
description: Understand the first multi-agent bundle in the gallery.
---

The Chief of Staff bundle demonstrates why Render Loops needs multiple runtime paths. The bundle deploys one shared loop, but each agent uses the runtime that matches its job.

## Bundle agents

- `chat`: Runs through web and worker services for interactive conversation.
- `meeting-prep`: Runs on Cron to create meeting briefs before upcoming events.
- `weekly-recap`: Uses Cron to trigger a durable Workflow recap.
- `interview-prep`: Uses Cron-triggered Workflows and can also run on demand.
- `interview-feedback`: Runs as an on-demand Workflow task.

## Shared pieces

All agents share the bundle manifest, model defaults, environment schema, Postgres state, and the memory capability. This keeps the deployment small while still letting each agent choose the right runtime shape.
