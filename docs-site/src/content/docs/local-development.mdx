---
title: Local Development
description: Run the harness locally and verify changes before deploying.
---

Use the repo root for workspace commands.

## Install dependencies

```sh
pnpm install
```

The workspace uses Node 22 or later and pnpm 10.

## Start local primitives

Most runtime and integration paths use Postgres and Key Value.

```sh
pnpm db:up
```

This starts Postgres on `127.0.0.1:55432` and Key Value on `127.0.0.1:56379`.

## Run examples

```sh
pnpm dev:web
pnpm dev:citations
pnpm dev:operator-web
pnpm dev:operator-worker
```

Use the example that matches the runtime path you are changing.

## Run docs locally

```sh
pnpm docs:dev
```

Build the docs before committing docs changes:

```sh
pnpm docs:build
```

## Validate code

```sh
pnpm typecheck
pnpm test
pnpm check
```

For a narrower loop, filter to the package you changed:

```sh
pnpm --filter @render-harness/core test
pnpm --filter @render-harness/registry typecheck
```

## Scaffolded project loop

For a project generated by `create-render-agent`, work from the generated project root:

```sh
pnpm install
cp .env.example .env
pnpm dev
```

If the generated project links to this checkout, use this repo's Compose stack for local primitives:

```sh
docker compose -f /path/to/render-harness/compose.yaml up -d --wait
```

Then call the local web service:

```sh
curl -sS http://localhost:8080/runs \
  -H 'content-type: application/json' \
  -d '{"input":"Hello!"}'
```
