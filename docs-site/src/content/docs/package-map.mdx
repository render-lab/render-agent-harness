The monorepo is easier to navigate when you group packages by job.

## Agent execution

- `packages/core`: The model loop, tools, MCP wiring, skills, state writes, budgets, and cancellation.
- `packages/contracts`: Browser-safe shared types for the server and SPA.
- `packages/capabilities/*`: Optional tool packs that add local tools, MCP servers, skills, and environment requirements.

## Runtime entrypoints

- `packages/runtime-web`: A synchronous HTTP runtime for demos and short runs.
- `packages/runtime-worker`: A queue consumer for production interactive work.
- `packages/runtime-cron`: A scheduled one-shot runtime.
- `packages/runtime-workflows`: A durable Render Workflows runtime.

## Product surface

- `packages/web`: The public HTTP API, run queueing, SSE streams, and optional UI mount.
- `packages/ui`: The operator SPA served at `/ui`.

## Authoring and deploy

- `packages/registry`: Config schema, capability loading, gallery loading, and `render.yaml` emission.
- `packages/create-render-agent`: The CLI scaffolder and bundled gallery snapshot.
- `packages/wizard`: The browser scaffolder that creates managed repos and deploy links.

## Templates and examples

- `gallery`: Curated agent templates and bundles.
- `examples`: Runnable examples for local and Render-style development.
- `blueprints`: Reference Render Blueprints for the supported deployment shapes.
