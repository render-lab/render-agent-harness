---

The monorepo is easier to navigate when you group packages by job.

## Agent execution

| Package | npm | Owns |
| --- | --- | --- |
| `packages/core` | [`@render-harness/core`](https://www.npmjs.com/package/@render-harness/core) | The model loop, tools, MCP wiring, skills, state writes, budgets, and cancellation. |
| `packages/contracts` | [`@render-harness/contracts`](https://www.npmjs.com/package/@render-harness/contracts) | Browser-safe shared types for the server and SPA. |
| `packages/capabilities/*` | [Capability packages](https://www.npmjs.com/search?q=keywords%3Arender-harness-cap) | Optional tool packs that add local tools, MCP servers, skills, and environment requirements. |

## Runtime entrypoints

| Package | npm | Owns |
| --- | --- | --- |
| `packages/runtime-web` | [`@render-harness/runtime-web`](https://www.npmjs.com/package/@render-harness/runtime-web) | A synchronous HTTP runtime for demos and short runs. |
| `packages/runtime-worker` | [`@render-harness/runtime-worker`](https://www.npmjs.com/package/@render-harness/runtime-worker) | A queue consumer for production interactive work. |
| `packages/runtime-cron` | [`@render-harness/runtime-cron`](https://www.npmjs.com/package/@render-harness/runtime-cron) | A scheduled one-shot runtime. |
| `packages/runtime-workflows` | [`@render-harness/runtime-workflows`](https://www.npmjs.com/package/@render-harness/runtime-workflows) | A durable Render Workflows runtime. |

## Product surface

| Package | npm | Owns |
| --- | --- | --- |
| `packages/web` | [`@render-harness/web`](https://www.npmjs.com/package/@render-harness/web) | The public HTTP API, run queueing, SSE streams, and optional UI mount. |
| `packages/ui` | [`@render-harness/ui`](https://www.npmjs.com/package/@render-harness/ui) | The operator SPA served by each deployed loop. |

## Authoring and deploy

| Package | npm | Owns |
| --- | --- | --- |
| `packages/registry` | [`@render-harness/registry`](https://www.npmjs.com/package/@render-harness/registry) | Config schema, capability loading, gallery loading, and `render.yaml` emission. |
| `packages/create-render-agent` | [`create-render-agent`](https://www.npmjs.com/package/create-render-agent) | The CLI scaffolder and bundled gallery snapshot. |
| `registry-index` | Community index | Submitted loop repos shown on `/browse`. |
| `apps/wizard` | Not published | The browser scaffolder that creates managed repos and deploy links. Deployed as a Render web service from this repo. |

## Templates and examples

- `gallery`: Curated agent templates and bundles.
- `examples`: Runnable examples for local and Render-style development.
- `blueprints`: Reference Render Blueprints for the supported deployment shapes.
