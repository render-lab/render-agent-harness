## Templates

Starter templates that community devs copy into their own repos.

- [`render-harness-entry/`](./render-harness-entry/) — the canonical "new entry" scaffolding for the config registry.
- [`capability-pack/`](./capability-pack/) — starter package for community-authored capability packs.

Long-term these will live in their own GitHub template repos so contributors can use the "Use this template" button. While they're still iterating, they live here for review.
