# Chat assistant

The simplest gallery entry — a single-turn HTTP chat agent.

**Runtime:** web only. HTTP requests go to `serveAgent` from `@render-harness/runtime-web` (or `serveWeb` + the operator UI if you toggle that on in the wizard).

**Use this as a starting point if:** you want the fastest path to a working agent and plan to add capabilities, MCP servers, or extra runtimes by hand later.
